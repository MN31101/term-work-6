# Планування впровадження модулів у МІС з квотами та ефектами взаємопідсилення

Курсова робота з дисципліни «Дослідження операцій в інформаційно-управляючих системах» (КПІ, ІС-34).

Задача: обрати підмножину модулів медичної інформаційної системи, що максимізує сумарний ефект
(базові ефекти + бонуси за пари модулів) за обмежень на ресурс, квоти напрямів і мінімум
модулів з пріоритетних напрямів.

## Запуск (з кореневої папки проєкту)

```
pip install -r requirements.txt
python cli.py                    # програма з меню
python -m tests.test_smoke       # перевірка коректності
python -m experiments.runner     # усі чотири експерименти (~15 хв), результати -> results/
```

## Структура

```
cli.py                  інтерфейс користувача (меню)
core/
  model.py              класи Problem і Solution: обмеження, цільова функція, приріст Δ_i(S)
  generator.py          генератор індивідуальних задач
  io_json.py            збереження / читання / перевірка задач у JSON
algorithms/
  greedy.py             жадібний алгоритм (дві фази, критерій Δ_i(S)/a_i)
  genetic.py            генетичний алгоритм (турнір, рівномірне схрещення, мутація, елітизм)
  annealing.py          імітація відпалу (обмін + ремонт + доповнення, T := α·T)
  repair.py             ремонт недопустимих розв'язків (для ГА та ІВ)
  exact.py              повний перебір (n ≤ 20) і верхня межа LP-релаксації
experiments/
  runner.py             експерименти: k, I (ГА), α (ІВ), вплив розмірності n
tests/
  test_smoke.py         автоматичні перевірки
data/
  example_task.json     індивідуальна задача №1 з пояснювальної записки
results/                CSV і PNG результатів експериментів; results/cli/ — запуски з меню
```
